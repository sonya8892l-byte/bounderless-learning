# 平台能力标签树（draft）

> 状态：**draft，只用于占位打标签**｜覆盖属性：`overridable: false`（课程不能改平台树，只能引用节点）
> 边界：本文件定义的标签**没有任何运行行为**——不进浏览器、不进 Prompt、无 UI、无计算。见 [课程提交规范 §8](../COURSE-SUBMISSION-SPEC.md)。
> 更新：2026-08-07 补 §DC 对照表（存量两门课的 DC 编号 → 平台 CC/CQ 的建议落点）

平台维护两棵**跨课程可比**的树。课程侧另有两棵学科树（DK 学科知识 / DS 学科能力），写在各课 `objectives.md` 里。

**为什么需要平台树**：存量课程各自用 `DC-*` 编号，但**同一编号在不同课里含义不同**——格物课 `DC-01` 是"证据意识"，铸魂课 `DC-01` 是"实事求是"。课程内自洽，跨课完全不可比。平台 CC/CQ 就是那层可比的坐标；`DC-*` 保留为课程自己的说法，通过下面的对照表挂到平台树上。

标签在任务或 Step 上这样写：

```md
- 能力标签：CC-1.2, CQ-4, DK-03, DS-02
```

一个任务通常挂 1–2 个 CC、0–1 个 CQ 即可，不必挂满。挂不准没关系，这一版只要位置留对。

## CC 核心能力

跨学科的通用认知与行动能力，是研学课程最主要的育人目标。

| ID | 名称 | 观察点 |
|---|---|---|
| CC-1 | **观察与描述** | 从真实现场提取可复述的细节 |
| CC-1.1 | 定向观察 | 按目标在复杂现场中找到关键对象 |
| CC-1.2 | 特征描述 | 用可核对的语言说明形状、方位、数量、材质 |
| CC-1.3 | 记录留证 | 用照片、录音、文字留下他人可复核的证据 |
| CC-2 | **测量与数据** | 获得并处理定量信息 |
| CC-2.1 | 工具测量 | 正确使用测量工具与单位 |
| CC-2.2 | 估算 | 在无法直接测量时给出合理量级 |
| CC-2.3 | 数据整理 | 记录、对比、发现异常值 |
| CC-3 | **推理与论证** | 从证据走到结论 |
| CC-3.1 | 因果推断 | 区分相关与因果，说明机制 |
| CC-3.2 | 证据支撑 | 让每个结论都指向具体证据 |
| CC-3.3 | 反例检验 | 主动寻找不支持自己结论的情况 |
| CC-4 | **建模与迁移** | 抽象出结构并用到新场景 |
| CC-4.1 | 简化建模 | 用图示或结构说明现象 |
| CC-4.2 | 跨场景迁移 | 把在此处学到的方法用到别处 |
| CC-5 | **方案与决策** | 在约束下做出可执行选择 |
| CC-5.1 | 方案设计 | 提出满足约束条件的具体做法 |
| CC-5.2 | 权衡取舍 | 在成本、风险、收益之间明确取舍理由 |
| CC-5.3 | 结果复盘 | 依据结果修订自己的判断 |

## CQ 综合素质

学习过程中的态度、协作与表达，通常通过任务的组织方式培养，而非知识内容。

| ID | 名称 | 观察点 |
|---|---|---|
| CQ-1 | **自主学习** | 主动提问、自定步调、遇阻不停 |
| CQ-2 | **协作沟通** | 分工、倾听、把自己的发现讲清楚给同伴 |
| CQ-3 | **表达展示** | 面向他人有结构地呈现过程与结论 |
| CQ-4 | **文化理解** | 对文化遗产的价值与处境形成自己的认识 |
| CQ-5 | **责任与伦理** | 尊重现场规则、保护对象、如实记录 |
| CQ-6 | **审美感知** | 感受形式、材质、空间带来的秩序与美 |

## DC 对照表（存量课程编号 → 平台树）

`DC-*` 是课程私有编号，**不跨课比较**。下表是建议落点，供后续升级用；现阶段两边并存，课程源文件不动。

一条 DC 可能同时落在 CC 和 CQ 上（认知能力 + 态度倾向），这是正常的——它们本来就是两种维度。

### 新课怎么写

新课程**直接写 `CC-*` / `CQ-*`**，不要再造 `DC-*`。学科专属的知识与能力仍写 `DK-*` / `DS-*`。

## 使用约定

1. **只增不改**：已发布的 ID 语义不再改动；需要调整时新增子节点，旧 ID 保留。
2. **两级为限**：`CC-3.1` 这样两级足够，不再往下分。
3. **课程不扩展平台树**：课程要表达学科专属能力时用本课 `objectives.md` 的 DK/DS，不要自造 CC/CQ 编号。
4. **draft 期允许整体重排**：迁移完成前，这两棵树可以整体调整；届时用脚本批量替换课程里的标签。
5. **升级要人工过一遍**：真要把 `DC-*` 换成平台编号时，按上面对照表逐条改，改完人工抽查。不要写"DC-0N → CC-N"这种规则脚本。
