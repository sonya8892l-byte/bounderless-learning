# 阶段编排

## Phase 1：问题界定
- 时长：第1周
- 模式：博物馆导入 + 研究开题
- 地点：国家动物博物馆或教育空间
- 功能模块：A06(案例媒体), A01(研究问题), A05(开题答辩)
- 触发条件：教师手动启动
- 结束条件：研究对象、概念、范围、伦理与六线计划通过开题

### 流程
1. 从鸟类适应、迁徙与城市生境案例提出问题。
2. 区分鸟撞事件、风险代理指标、规范要求和政策建议。
3. 确定一处校园/机构研究范围与替代范围。
4. 完成研究问题、角色分工、伦理与AI使用计划。

## Phase 2：科学取证与建筑风险调查
- 时长：第2—4周
- 模式：文献研究 + 教师批准的重复调查
- 地点：资料空间与校园/机构建筑外围
- 功能模块：A01(照片/数据), A03(反射标注/风险图), A07(实物识别)
- 触发条件：开题、路线和安全方案获教师确认
- 结束条件：形成可复核调查数据、风险图和科学证据综述

### 流程
1. 阅读国内公民科学与主管部门材料，建立变量表。
2. 按固定路线和时段观察玻璃反射、通透、绿植与照明。
3. 对照片去除个人信息，记录零发现和调查限制。
4. 形成高、中、低风险点位图；教师完成安全与数据抽检。

## Phase 3：中国规范与域外比较
- 时长：第3—5周
- 模式：规范检索 + 三城比较
- 地点：资料空间
- 功能模块：A03(规范层级图/比较矩阵), A01(原文摘录)
- 触发条件：研究对象与主要风险变量明确
- 结束条件：中国规范地图和多伦多、纽约、旧金山比较报告完成

### 流程
1. 核对中国现行法律、已公布待施行法典和深圳实践。
2. 区分法律、地方标准、设计指引、机构规则和倡议。
3. 仅用三城官方原文比较适用范围、措施、程序与执行。
4. 记录版本、效力、适用条件和不可直接移植之处。

## Phase 4：社会调查
- 时长：第5—7周
- 模式：匿名问卷/访谈 + 主题编码
- 地点：教师批准的线上或线下空间
- 功能模块：A01(匿名调查), A05(访谈), A03(编码墙)
- 触发条件：知情同意文本与问题清单获教师批准
- 结束条件：形成匿名数据集、编码记录、局限与社会调查报告

### 流程
1. 确定需要了解的知识、态度、成本与执行条件。
2. 试访谈后修改诱导、隐私或无法回答的问题。
3. 收集最少必要信息，去标识化并允许退出。
4. 双人编码分歧，公开样本边界和未代表群体。

## Phase 5：起草听证与修订
- 时长：第7—10周
- 模式：成本效果模拟 + 模拟听证 + 三稿修订
- 地点：教育空间
- 功能模块：A04(成本效果), A05(听证), A01(条款与版本)
- 触发条件：四线证据包通过完整性检查
- 结束条件：建议稿三稿、听证记录和意见处置表完成

### 流程
1. 用规则“五问”形成初稿并逐条绑定证据。
2. 模拟不同预算、建筑条件和例外情境。
3. 由科学、管理、使用者和权益视角公开听证。
4. 对每条意见记录采纳状态、理由和条款变化。

## Phase 6：表决发布与真实转化
- 时长：第10—12周
- 模式：课程表决 + 研究发布 + 可选真实沟通
- 地点：教育空间或经批准的发布场所
- 功能模块：A05(表决), A01(发布包)
- 触发条件：终稿通过科学、规范、伦理和程序审查
- 结束条件：课程表决、少数意见、AI披露和后续路径完整

### 流程
1. 按条款或整案进行课程内部表决。
2. 发布赞成理由、反对/保留意见和未解问题。
3. 明示“青少年建议稿”，不宣称正式立法或机构采纳。
4. 如获授权，可向校园/机构提交；记录接收状态，不把提交等同采纳。
