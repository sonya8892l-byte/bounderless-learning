# lesson_zhizhi_003

研究性学习版《万兽城议事厅Ⅲ：一条防鸟撞规则的诞生》的课程源包。

## 教研备忘（不参与运行）

### 默认议题与成果

> 教研说明：本节记录课程选题与成果设计，不作为运行时自动建任务或自动发布配置。
- 默认议题：校园与城市玻璃建筑鸟撞治理。
- 四线证据包：科学与建筑风险、中国规范、域外制度、社会与影响评估。
- 最终成果：鸟撞风险图、规范地图、三城比较报告、社会调查报告、成本效果模拟、听证记录、三稿对照、青少年防鸟撞规则建议稿。

### 研究与效力边界

> 教研说明：本节是全课研究与发布边界；具体运行时限制仍以 `course.md / 课程限制规则`、Phase Prompt 与 Step 引用为准。
- 建议稿限定为校园或机构可讨论的治理建议，不表述为正式立法、法律意见或已获采纳。
- 建议稿须覆盖适用对象、玻璃措施、照明措施、监测报告、责任主体、成本、申诉救济、例外与复核周期。
- 调查路线、拍摄范围、匿名访谈和数据发布须经教师审批；不采集无关个人信息。
- 学生不触碰、移动或自行救治受伤/死亡鸟类，发现后按当地主管部门或机构流程报告。
- AI可协助提问、编码、比较和三稿对照；所有来源、统计、法律效力与最终条款由学生和人工核验人负责。

## 运行结构
- 8—12周、6阶段、6角色；每角色3个研究阶段，每阶段2个Step。
- B1知识卡按研究进度和角色开放，动态规范保留发布日期、访问日期和人工核验提示。
- `time-bank.md` 已启用，提供研究方法、风险调查和规则修订支线；余额不越过伦理与程序门槛。
- `assets/placeholders/` 只用于确保素材引用可解析。

## 输出边界
- 终稿名称固定为“青少年防鸟撞规则建议稿”。
- 课程表决只说明课程内部态度，不产生正式法律或机构效力。
- 如获授权提交校园或机构，记录“已提交/已接收/反馈中/采纳或未采纳”的真实状态。
