# 中国规范研究员

> 核心问题：中国现有材料分别处于什么规范层级，何时生效，能支持怎样的本地建议？

## 基本信息
- 排序：2
- 地点：资料空间
- 地理围栏：课程资料与教师批准检索范围
- 类型：核心角色
- 选择说明：建立中国规范地图，核对法律效力日期，研究深圳标准与实践。
- 角色卡图：assets/placeholders/role-card.svg
- 角色徽章图：assets/placeholders/badge.svg
- 收集物：规范章
- 收集物图：assets/placeholders/token.svg

## 任务列表

### 任务1：建立规范检索框架
- id：china-frame-norms
- 阶段：Phase 1 问题界定
- 地点：教育空间
- 位置模式：none
- 建议时长：1课时
- 推进方式：auto_after_validation
- 任务图：assets/placeholders/task.svg
- 配置：先区分层级、效力与研究问题，再开展检索
- 通过条件：形成规范层级图和五字段来源登记规则

##### 引导
- 逐份追问制定主体、文件形式和适用范围。
- 公布日、施行日和调查日状态分开记录。

##### 脚手架
| L0 | 先写谁制定、文件叫什么。 |
| L1 | 放入法律、标准、指引或倡议。 |
| L2 | 补公布日与施行日。 |
| L3 | 补范围、强制性和核验人。 |
| L4 | 规范核验人处理层级争议。 |

#### Step 1：区分材料层级
- id：china-sort-materials
- 小步目标：避免把倡议、指引、标准和法律混写
- 学生行动：将候选材料按制定主体、形式和效力初步分类，未知项保留待核
- 位置：none
- 完成方式：ai_evaluation
- 证据要求：至少6条材料分类，含2条待核理由
- 功能模块：A03(规范层级图)
- 工具参数：{"builder":{"mode":"hierarchy","prompt":"按法律、法规/规章、标准、指引、机构规则、倡议分类；不确定时标待核。","minimumItems":6,"categories":["法律","法规或规章","标准","设计指引","机构规则","倡议","待核"]}}
- 知识引用：K-07
- 限制引用：course.md#课程限制规则/法律效力
- 常见误区：政府网站出现的材料都标成法律
- 最大尝试：3
- 失败处理：逐项追问谁制定、叫什么、用什么形式发布
- 教师介入：层级判断涉及专业法律问题
- 通过后：step:china-set-record-fields

##### 验收标准
至少6条材料分类，含2条待核理由
- S1 开题：范围、问题、方法、安全、伦理、AI计划由教师确认。

#### Step 2：制定效力登记表
- id：china-set-record-fields
- 小步目标：让每份规范可追溯且可更新
- 学生行动：确定名称、机关、文号/版本、公布日、施行日、范围、强制性和访问日字段
- 位置：none
- 完成方式：tool_result
- 证据要求：字段齐全并指定人工核验人
- 功能模块：A01(规范登记表)
- 工具参数：{"text":{"fields":[{"id":"protocol","label":"规范登记字段与核验流程","type":"long_text","required":true,"minLength":100},{"id":"reviewer","label":"人工核验人/岗位","type":"short_text","required":true}]}}
- 知识引用：K-07, K-22
- 限制引用：course.md#课程限制规则/法律效力
- 常见误区：只有发布日期，没有施行日期
- 最大尝试：2
- 失败处理：提示公布和生效可能是两个时间

登记模板包含名称、制定机关、文号或版本、公布日、施行日、适用范围、强制性和访问日，并明确人工核验人。


### 任务2：核验中国规范与深圳实践
- id：china-build-map
- 阶段：Phase 3 中国规范与域外比较
- 地点：资料空间
- 位置模式：none
- 建议时长：2周
- 推进方式：auto_after_validation
- 任务图：assets/placeholders/task.svg
- 配置：核验野生动物保护法、生态环境法典时间状态和深圳地方标准
- 通过条件：三类核心材料原文、效力、范围和人工签注完整

##### 引导
- 法律与标准只用官方原文，关键效力交人工签注。
- 征求意见稿、正式标准和实施案例放在不同时间节点。

##### 脚手架
| L0 | 从官方原文定位。 |
| L1 | 法律与法典分别记时间状态。 |
| L2 | 深圳材料按时间线排列。 |
| L3 | 区分征求意见、标准和实践。 |
| L4 | 人工签注效力与条文。 |

#### Step 1：核对法律时间状态
- id：china-verify-laws
- 小步目标：准确表达当前法与已公布待施行法典
- 学生行动：定位原文，记录公布/修订日、施行日、相关条文、范围和当前状态
- 位置：none
- 完成方式：teacher_confirm
- 证据要求：野生动物保护法与生态环境法典分别登记；截至调查日的状态清楚
- 功能模块：A01(文字记录)
- 工具参数：{"text":{"fields":[{"id":"wildlife-law","label":"野生动物保护法原文与效力记录","type":"long_text","required":true,"minLength":100},{"id":"code","label":"生态环境法典原文与时间状态","type":"long_text","required":true,"minLength":100}]}}
- 知识引用：K-08, K-09
- 限制引用：course.md#课程限制规则/法律与公共表达
- 常见误区：把已公布待施行写成调查日现行
- 最大尝试：1
- 失败处理：保留“效力待核”，不进入确定性条款依据
- 教师介入：必须
- 通过后：step:china-study-shenzhen

##### 验收标准
两份法律材料分别记录官方原文位置、条文、公布或修订日、施行日、适用范围及调查日状态，并经人工核验。

### 任务3：交付规范地图
- id：china-deliver-map
- 阶段：Phase 5 起草听证与修订
- 地点：教育空间
- 位置模式：none
- 建议时长：1课时
- 推进方式：auto_after_validation
- 任务图：assets/placeholders/task.svg
- 配置：说明哪些材料提供原则、技术参考或本地程序依据
- 通过条件：规范地图、可引用结论、不可推出事项和更新提示完整

##### 引导
- 每份材料写清可支持、不能直接推出和更新条件。
- 发现“依法必须”等高风险表述立即转人工审查。

##### 脚手架
| L0 | 每份材料写可支持什么。 |
| L1 | 再写不能推出什么。 |
| L2 | 加更新条件。 |
| L3 | 抽查五条建议条款。 |
| L4 | 教师确认无正式法律意见。 |

#### Step 1：制作规范地图与边界
- id：china-compose-norm-map
- 小步目标：让起草组知道每份材料能支持到哪里
- 学生行动：按层级呈现材料，并为每份写“可支持/不能直接推出/需更新”
- 位置：none
- 完成方式：ai_evaluation
- 证据要求：至少5份材料有三类边界说明和来源编号
- 功能模块：A03(规范地图)
- 工具参数：{"builder":{"mode":"norm_map","prompt":"每份材料记录层级、效力、范围、可支持、不能直接推出和更新条件。","minimumItems":5}}
- 知识引用：K-07, K-08, K-09, K-10
- 限制引用：course.md#课程限制规则/法律效力
- 常见误区：从保护原则直接推出具体点距或处罚
- 最大尝试：3
- 失败处理：将超出材料的句子改成课程建议选择
- 教师介入：存在具体权利义务或责任判断
- 通过后：step:china-review-clauses

##### 验收标准
至少5份材料按层级登记，每份均有来源编号及“可支持、不能直接推出、需更新”三类边界说明。


#### Step 2：审查条款效力表述
- id：china-review-clauses
- 小步目标：避免建议稿把参考依据写成强制本地要求
- 学生行动：抽查至少5条条款，标注现行依据、借鉴依据、课程选择或待核
- 位置：none
- 完成方式：teacher_confirm
- 证据要求：5条以上审查记录，法律与标准结论由人工签注
- 功能模块：A05(条款审查)
- 工具参数：{"team":{"mode":"clause_review","prompt":"逐条标注现行依据、借鉴依据、课程选择或待核；完成后交由教师确认条款未冒充现行法律义务或正式法律意见。","minimumEntries":5}}
- 知识引用：K-07, K-23
- 限制引用：course.md#课程限制规则/法律与公共表达
- 常见误区：用“依法必须”描述课程自拟措施
- 最大尝试：1
- 失败处理：改写为建议用语并保留待核
- 教师介入：必须
- 通过后：role:complete

##### 验收标准
5条以上审查记录，法律与标准结论由人工签注
- S5 起草：每条规则有证据、主体、执行、例外或待核说明。
