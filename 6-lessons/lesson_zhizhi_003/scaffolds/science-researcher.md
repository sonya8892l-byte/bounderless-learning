# 科学证据研究员分级脚手架

## 任务1：设计可复现调查
| 层级 | 提示 |
|---|---|
| L0 | 先写你认为的两条机制。 |
| L1 | 区分事件与风险变量。 |
| L2 | 补路线、时段、天气和零发现。 |
| L3 | 写可能削弱假设的证据。 |
| L4 | 教师提供安全替代路线。 |

## 任务2：执行建筑风险调查
| 层级 | 提示 |
|---|---|
| L0 | 每轮先填元数据。 |
| L1 | 照片标反射、通透、绿植或照明。 |
| L2 | 没发现也要记录。 |
| L3 | 风险图分事件、变量与未知。 |
| L4 | 教师处理事件和隐私。 |

## 任务3：交付科学证据线
| 层级 | 提示 |
|---|---|
| L0 | 写能判断和不能判断。 |
| L1 | 补六个来源或数据编号。 |
| L2 | 恢复反例与局限。 |
| L3 | 接受一条替代解释质询。 |
| L4 | 科学核验人确认高风险结论。 |
