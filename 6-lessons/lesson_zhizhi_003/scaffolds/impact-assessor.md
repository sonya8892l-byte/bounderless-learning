# 影响评估员分级脚手架

## 任务1：定义评估框架
| 层级 | 提示 |
|---|---|
| L0 | 先说措施希望改变什么。 |
| L1 | 补指标、单位和时间。 |
| L2 | 区分实测、资料与假设。 |
| L3 | 用区间表示不确定。 |
| L4 | 教师排除敏感成本数据。 |

## 任务2：模拟措施组合
| 层级 | 提示 |
|---|---|
| L0 | 做基础、重点、强化三组。 |
| L1 | 每组补覆盖、效果、成本、维护。 |
| L2 | 所有数值回到假设账本。 |
| L3 | 改两个参数看推荐是否变化。 |
| L4 | 教师处理结构安全问题。 |

## 任务3：交付影响评估
| 层级 | 提示 |
|---|---|
| L0 | 区分模型估计和实际成效。 |
| L1 | 补局限与复核触发。 |
| L2 | 回应预算质询。 |
| L3 | 回应公平质询并给替代。 |
| L4 | 教师确认无采购承诺。 |
