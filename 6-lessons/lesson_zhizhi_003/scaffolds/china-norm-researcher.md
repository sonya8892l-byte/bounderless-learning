# 中国规范研究员分级脚手架

## 任务1：建立规范检索框架
| 层级 | 提示 |
|---|---|
| L0 | 先写谁制定、文件叫什么。 |
| L1 | 放入法律、标准、指引或倡议。 |
| L2 | 补公布日与施行日。 |
| L3 | 补范围、强制性和核验人。 |
| L4 | 规范核验人处理层级争议。 |

## 任务2：核验中国规范与深圳实践
| 层级 | 提示 |
|---|---|
| L0 | 从官方原文定位。 |
| L1 | 法律与法典分别记时间状态。 |
| L2 | 深圳材料按时间线排列。 |
| L3 | 区分征求意见、标准和实践。 |
| L4 | 人工签注效力与条文。 |

## 任务3：交付规范地图
| 层级 | 提示 |
|---|---|
| L0 | 每份材料写可支持什么。 |
| L1 | 再写不能推出什么。 |
| L2 | 加更新条件。 |
| L3 | 抽查五条建议条款。 |
| L4 | 教师确认无正式法律意见。 |
