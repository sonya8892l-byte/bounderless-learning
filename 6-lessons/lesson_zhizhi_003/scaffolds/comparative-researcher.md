# 域外制度研究员分级脚手架

## 任务1：制定三城原文协议
| 层级 | 提示 |
|---|---|
| L0 | 找到三城官方机构页面。 |
| L1 | 记录标题、URL和访问日。 |
| L2 | 使用统一七项字段。 |
| L3 | 设计原文—译文—复核三栏。 |
| L4 | 教师处理页面或版本问题。 |

## 任务2：完成三城比较
| 层级 | 提示 |
|---|---|
| L0 | 每城先提取三段短原文。 |
| L1 | 补适用对象和例外。 |
| L2 | 空格写未找到、不适用或待核。 |
| L3 | 标两项不可直接比较。 |
| L4 | 第二复核人确认译文。 |

## 任务3：形成可借鉴性报告
| 层级 | 提示 |
|---|---|
| L0 | 选择三项候选做法。 |
| L1 | 问本地问题是否相似。 |
| L2 | 补主体权限和成本条件。 |
| L3 | 写试点、例外与不移植项。 |
| L4 | 规范核验人处理权限问题。 |
