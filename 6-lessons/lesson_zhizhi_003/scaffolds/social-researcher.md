# 社会调查员分级脚手架

## 任务1：完成伦理与工具送审
| 层级 | 提示 |
|---|---|
| L0 | 先说需要听见哪些群体。 |
| L1 | 每个数据字段写用途。 |
| L2 | 补同意、跳过和退出。 |
| L3 | 用两名同伴试测问题。 |
| L4 | 教师审批未成年人和录音。 |

## 任务2：匿名收集与双人编码
| 层级 | 提示 |
|---|---|
| L0 | 同意状态和匿名回答分开。 |
| L1 | 删除姓名、联系方式和身份组合。 |
| L2 | 两人先独立编码小批材料。 |
| L3 | 记录分歧、定义修订和反例。 |
| L4 | 教师处理撤回与意外身份信息。 |

## 任务3：提交社会调查报告
| 层级 | 提示 |
|---|---|
| L0 | 写方法、主题和样本范围。 |
| L1 | 补反例和未代表群体。 |
| L2 | 使用条件化结论。 |
| L3 | 做匿名抽查与删除日志。 |
| L4 | 教师批准公开版本。 |
