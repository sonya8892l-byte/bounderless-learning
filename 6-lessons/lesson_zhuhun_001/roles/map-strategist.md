- id：task-1
- 位置模式：inherit_role

- 建议时长：15min

- 功能模块：A01(拍照采集), A07(扫码), 位置导航

- 配置：找到长征路线地图或地形模型，拍摄至少2处允许拍摄的局部；分别标注赤水河、乌江、长江、金沙江中能够辨认的水系，并记录展项标题
- 通过条件：至少2张有效证据照片 + 1条展项来源 + 至少2个正确空间标注
- 目标关联：K1(时空坐标), S1(地图判读), S3(史料实证)
- 能力标签：DK-01, DS-01, DS-03

##### 引导
**引导目标**
帮助学生先确认地图方向和图例，再从展项中提取河流、山地与区域位置，形成可追溯的空间证据。

**引导策略**
- 先问：“你用什么确认这张图的上方代表哪一方向？”
- 学生只报地名时追问：“它在赤水河的哪一侧？和另一条河是什么相对位置？”
- 对照片进行OCR或图像识别时，低置信度文字标为“待人工核对”。
- 引导每个标注附上展项标题或照片编号。
- 找不到目标展项时调用导航；场馆动线变化时建议呼叫老师。

**绝对禁止**
- 不在学生找到证据前提供四渡完整路线。
- 不依据模糊照片猜地名、日期或部队位置。
- 不引导学生离开场馆允许动线。

##### 脚手架
| L0 | 肯定其定位依据，并请学生继续记录来源。 |
| L1 | “先找指北针、经纬线或熟悉的河流名称，哪一个能帮你定方向？” |
| L2 | 提供四项核对框：方向、图例、河流名称、展项标题。 |
| L3 | 示范读取一处公开图例：“我先确认蓝线代表水系，再沿蓝线寻找名称；下一处由你来找。” |
| L4 | 打开可操作标注模板，让学生从现场照片中点选两个可见地名；无法辨认时标“待核”，不补史实路线。 |

##### 引导
**引导目标**
让学生把“看到的位置”转化为“会影响行动的空间约束”，并区分事实标注与推演标注。

**引导策略**
- 依次追问：“哪里能通行？哪里难通行？哪里容易被封锁？”
- 每放置一个敌我位置，要求选择证据类型：展项、权威资料、课程材料或个人推断。
- 提醒学生同时考虑渡河、山地、补给和交通线，不用单一因素解释路线。
- 当路线断裂时只指出断点：“从A到B之间还缺哪个地理条件？”

**绝对禁止**
- 不把候选渡口直接标成史实渡口。
- 不用后续战果证明当前路线必然可行。
- 不替学生完成底图标注。

### 任务3：拟路线

- 提醒冷却：8min

- 功能模块：A01(画板标注), A02(表单)
- 任务图：assets/tasks/terrain-map.svg
- 配置：只依据本角色已采集证据，提出一条阶段性转移路线；填写目标、地形优势、主要风险、仍缺信息各1项
- 通过条件：提交1条连续路线 + 4项理由完整 + 至少引用2条现场证据
- 目标关联：K3(四次渡河), S5(决策矩阵), C1(实事求是), C2(战略思维)

##### 引导
**引导目标**
帮助学生在有限证据下提出可复核的阶段方案，同时清楚记录未知和风险。

**引导策略**
- 使用四问：“目标是什么？哪条地形证据支持？最大风险是什么？还缺什么情报？”
- 如果学生只画一条线，追问路线连续性与备用出口。
- 如果学生频繁改线，帮助保留版本并标出触发变化的新证据。
- 提交后评价证据链完整度，不评价是否与史实一致。

**绝对禁止**
- 不说“正确路线”“标准答案”或暗示后续方向。
- 不删除学生的初始方案和修改痕迹。
- 不把AI常识生成的地图信息标成展馆证据。

| L0 | 追问路线中最脆弱的一环。 |
