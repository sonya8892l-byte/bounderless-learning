# 《万兽城议事厅Ⅰ：地球村居民ID Card》配置手册

## 课程定位
大众体验版以完整体验闭环为目标。学生共同代言一种动物，依次完成观察、求证、关系解释、表达、发布和行动。

## 目录约定
- `course.md`：课程身份、层级、角色体系与视觉引用。
- `phases.md`：120分钟六阶段流程。
- `roles/`：六种分工及结构化Step。
- `knowledge/`：带来源和揭示时机的信息卡。
- `guidance/`、`scaffolds/`：AI引导与L0—L4帮助。
- `restrictions.md`、`evaluation.md`：事实边界和验收标准。
- `time-bank.md`：已启用的观察、证据表达与组内互助支线任务。

## 实施前P0踏勘
1. 核验六种候选动物是否展出及展签原文。
2. 为每种动物记录主点、替代点、容纳人数、拍摄规则和最短停留时间。
3. 检查入口、安静录音区、制作区和发布区之间不逆行。
4. 更新知识卡的保护信息、发布日期、访问日期和专家复核人。

## 运行约束
- 位置暂用点位名称和教师确认，不提交未经踏勘的坐标。
- 每轮AI只提出一个问题或打开一个工具。
- 学生未观察前不整包展示物种知识。
- 时间银行不按速度计分，余额不能替代核心任务验收。
- 视频功能不可用时保留真人录音；网络不可用时使用纸质证据单与离线信息卡。

## 验收结果
- 每组至少6条事实，80%以上可追溯。
- 每人至少承担一个角色并提交可识别证据。
- 公开成果无未经核实事实或未经授权个人信息。
