# 生态关系员分级脚手架

## 任务1：收集关系节点
| 层级 | 提示 |
|---|---|
| L0 | 先自己找四类节点。 |
| L1 | 它吃什么、住哪里、与谁相连？ |
| L2 | 再找一种人类活动。 |
| L3 | 每项补来源或待核。 |
| L4 | 使用食物、家园、动物、人类四栏模板。 |

## 任务2：绘制关系网
| 层级 | 提示 |
|---|---|
| L0 | 先把研究动物放在中心。 |
| L1 | 每条线在说什么关系？ |
| L2 | 给箭头写“吃、依赖、帮助、威胁”。 |
| L3 | 加入一个待核节点和三段影响链。 |
| L4 | 与教师逐条核验争议关系。 |

## 任务3：提出基本需要
| 层级 | 提示 |
|---|---|
| L0 | 从关系图自己找关键条件。 |
| L1 | 少了哪项条件会影响最大？ |
| L2 | 写需要、威胁和措施。 |
| L3 | 说明措施改变威胁链哪一环。 |
| L4 | 用“因为—所以—建议”模板。 |
