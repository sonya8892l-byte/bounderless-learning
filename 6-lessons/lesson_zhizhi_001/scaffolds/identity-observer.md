# 身份观察员分级脚手架

## 任务1：确认居民
| 层级 | 提示 |
|---|---|
| L0 | 先自己找出标本主体和展签标题。 |
| L1 | 画面里能同时看见“动物”和“它叫什么”吗？ |
| L2 | 后退一步拍全景，再靠近拍标题。 |
| L3 | 使用“标本全景＋展签标题＋来源编号”三项清单。 |
| L4 | 请教师确认点位，学生继续负责记录。 |

## 任务2：观察特征
| 层级 | 提示 |
|---|---|
| L0 | 先说你看到了什么。 |
| L1 | 可以从颜色、形状、大小和位置观察。 |
| L2 | 选一个特征写“我看到……”。 |
| L3 | 再补“我推测……需要……核验”。 |
| L4 | 用三栏模板填写观察、推断、核验。 |

## 任务3：整理身份事实
| 层级 | 提示 |
|---|---|
| L0 | 自己检查五个字段。 |
| L1 | 学名看不清可以怎样诚实记录？ |
| L2 | 用“待核”保留空缺。 |
| L3 | 邀请展签记录员逐项对照。 |
| L4 | 请教师处理名称冲突。 |
