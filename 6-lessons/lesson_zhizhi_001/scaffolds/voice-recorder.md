# 声音记录员分级脚手架

## 任务1：选择脚本证据
| 层级 | 提示 |
|---|---|
| L0 | 先从小组证据中自己选择。 |
| L1 | 五段内容是否都能找到来源或标签？ |
| L2 | 前四段写证据编号，最后一段写角色期待。 |
| L3 | 删除无法证明的心理活动。 |
| L4 | 请展签记录员逐项核对。 |

## 任务2：完成自述
| 层级 | 提示 |
|---|---|
| L0 | 用自己的话完成初稿。 |
| L1 | 按“身份—生活—关系—影响—期待”检查。 |
| L2 | 每段只保留一个重点。 |
| L3 | 使用五句模板后再改成自己的语言。 |
| L4 | 教师帮助检查事实，学生亲自录音。 |

## 任务3：同伴事实核验
| 层级 | 提示 |
|---|---|
| L0 | 先听同伴的具体意见。 |
| L1 | 哪一句需要来源？ |
| L2 | 至少记录保留和修改各一项。 |
| L3 | 写明修改前后和理由。 |
| L4 | 冲突信息交教师复核。 |
