# ID设计员分级脚手架

## 任务1：接收证据
| 层级 | 提示 |
|---|---|
| L0 | 自己检查四类成果。 |
| L1 | 哪一类已经有证据，哪一类还待补？ |
| L2 | 先完成已到齐部分。 |
| L3 | 用“已到齐/待补”两区整理。 |
| L4 | 少于三类核心成果时请教师调整。 |

## 任务2：制作居民证
| 层级 | 提示 |
|---|---|
| L0 | 按证据填写，不追求华丽。 |
| L1 | 哪些字段是事实，哪些是建议？ |
| L2 | 给事实补编号，给期待补标签。 |
| L3 | 用正面身份、背面关系与建议结构。 |
| L4 | 教师协助核验动态信息。 |

## 任务3：发布前审查
| 层级 | 提示 |
|---|---|
| L0 | 自己完成四项检查。 |
| L1 | 除了错别字，还要检查什么？ |
| L2 | 依次查事实、边界、隐私、AI。 |
| L3 | 记录一项具体修改。 |
| L4 | 提交教师终审。 |
