# 阶段编排

## Phase 1：居民招募
- 时长：8min
- 模式：集体导入
- 地点：入口集合区
- 功能模块：A06(沉浸媒体), A01(文字)
- 触发条件：教师手动启动
- 结束条件：每组领取物种并提交3个问题

### 流程
1. 观看“万兽城换发居民证”任务邀请。
2. 每组领取一种动物剪影与候选点位。
3. 学生写下三个真正想查明的问题。
4. 絮絮说明四类信息：观察、资料、推断、期待。

## Phase 2：身份与生活取证
- 时长：27min
- 模式：角色分工 + 小组汇合
- 地点：经踏勘确认的展品主点或替代点
- 功能模块：A07(实物识别), A01(拍照/文字)
- 触发条件：Phase 1结束 + 教师开放角色领取
- 结束条件：身份、家园和生活事实完成初审

### 流程
1. 确认标本与展签来源。
2. 记录物种名、学名、形态、栖息地和生活方式。
3. 每条事实绑定照片或信息卡编号。
4. 冲突或缺失信息标记“待核”，不由AI补写。

## Phase 3：关系与影响
- 时长：27min
- 模式：个人采证 + 小组拼合
- 地点：展品点位附近允许停留区
- 功能模块：A03(拼合搭建), A01(画板/文字)
- 触发条件：Phase 2结束
- 结束条件：生态关系图与人类影响链完成

### 流程
1. 拼出食物、天敌、伙伴和栖息地条件。
2. 用箭头说明关系方向。
3. 将人类活动分为帮助、威胁和待判断。
4. 从已有证据推导一种基本需要。

## Phase 4：角色发声
- 时长：32min
- 模式：个人创作 + 同伴核验
- 地点：馆内安静区或教育空间
- 功能模块：A01(文字/录音), A05(同伴核验)
- 触发条件：Phase 3结束
- 结束条件：60秒脚本与录音通过事实复核

### 流程
1. 按身份、生活、关系、影响、期待五段写脚本。
2. 同伴逐句标记证据编号和信息类型。
3. 修改无来源、过度拟人或绝对化表达。
4. 录制30—60秒真人旁白。

## Phase 5：居民证制作
- 时长：16min
- 模式：小组协作
- 地点：教育空间
- 功能模块：A03(档案搭建), A01(文字)
- 触发条件：Phase 4结束
- 结束条件：ID Card字段完整并通过人工终审

### 流程
1. 汇总身份、家园、生态角色、主要风险、基本需要和保障建议。
2. 检查事实、推断和期待标签。
3. 生成居民ID Card草稿。
4. 教师或引导员完成事实复核。

## Phase 6：居民发布会
- 时长：10min
- 模式：小组发布 + 个人行动
- 地点：教育空间
- 功能模块：A05(提问), A01(文字/语音)
- 触发条件：Phase 5结束
- 结束条件：完成一次证据质询和一项行动承诺

### 流程
1. 每组展示ID Card并播放自述。
2. 回答一个“证据在哪里”的问题。
3. 保留仍待核验的信息。
4. 每人提交一项具体、可观察、在一周内可复盘的行动。
