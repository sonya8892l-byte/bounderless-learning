# 课程提交完整案例（v2）

> 配套规范：[`COURSE-SUBMISSION-SPEC.md`](./COURSE-SUBMISSION-SPEC.md)
> 基准日期：2026-08-10
> 假设课程：`lesson_example_001`《紫禁城色彩证据局：颜色会说话吗？》
> 用途：交给课程开发、教研、素材和实施团队，作为“每个文件写什么、每个字段怎样填”的完整参考。

## 1. 使用方法与边界

这是一份**单文件展开版案例**。每个“文件示例”代码块都标明了目标路径；正式开发时，把代码块内容分别保存到 `6-lessons/lesson_<系列>_<编号>/` 下的对应文件。

案例中的课程、地点、坐标、素材、来源与活动安排均用于演示格式。正式课程必须由课程团队复核事实、现场安全、隐私、版权、开放区域、坐标和教师组织条件。

使用时遵守以下约定：

1. 保留标题层级、字段名、英文枚举与 ID 格式，替换示例值。
2. `工具参数` 始终写成**单行合法 JSON**；不要加注释、单引号或尾随逗号。
3. 示例外的说明文字不要复制进目标课程文件；代码块内的内容可直接作为起稿。
4. v2 新课程把引导、脚手架和验收标准就地写入任务或 Step，不再创建 `guidance/`、`scaffolds/`。
5. `_platform/` 是平台维护区，不属于单课提交包；课程只在 `course.md` 的允许小节中覆盖平台默认。
6. `open`、`inquiry` 遍历模式仍按 `sequential` 执行；正式上线课程先用 `sequential`。
7. 领取角色前的阶段任务已可运行；领取角色后的全班/小组阶段任务尚未实现聚合进度，案例中保留它们用于说明正确归属，现场仍需教师组织。
8. `能力标签` 当前只保存数据，不进入学生端、Prompt、UI 或评价计算。

## 3. 全局填写规则

| 项目 | 填写规则 | 本案例 |
|---|---|---|
| 课程目录 ID | `lesson_<系列代码>_<三位编号>`；上线后保持稳定 | `lesson_example_001` |
| 文件 slug | 小写英文 kebab-case；角色 ID 直接来自角色文件名 | `color-evidence.md` → `color-evidence` |
| Task ID | 同一角色内唯一；阶段任务在同一 Phase 内唯一 | `color-observe-site` |
| Step ID | 课程内尽量全局唯一，便于日志排查 | `color-capture-pair` |
| 知识 ID | `K-` + 两位数字；标题和 `知识引用` 必须逐字一致 | `K-01` |
| 能力标签 | 新课用 `CC-*`、`CQ-*`、`DK-*`、`DS-*` | `CC-1.2, DK-01, DS-02` |
| 前置 | 角色任务只能指同角色 Task；阶段任务只能指同 Phase 的阶段任务 | `color-observe-site` |
| 通过后 | `step:<stepId>`、`role-stage:<taskId>`、`role:complete` | `step:color-capture-pair` |
| 素材路径 | `course.md`、角色字段写 `assets/...`；工具 JSON 中写相对 `assets/` 的路径 | `tasks/color-observe.svg` |
| 私有答案 | 可写在 Markdown 中供服务端判定；不得放入学生可见文案或静态公开文件 | `answer`、`expectedResults` |

```md
# 课程目标体系

## 学科知识 DK
- DK-01 色彩观察条件：理解光线、距离、角度、表面状态会改变颜色观感
- DK-02 建筑色彩构成：认识墙面、屋面、彩画与石构件形成的综合色彩关系
- DK-03 证据与解释边界：区分现场观察、材料信息、资料解释和个人联想
- DK-04 色彩保护意识：理解不触摸、不取样、不遮挡通行是现场研究底线

## 学科能力 DS
- DS-01 规范采证：在同一对象上取得含环境、细节和记录条件的证据组
- DS-02 对照描述：使用可比较的词汇描述两处颜色或纹样的相同与差异
- DS-03 来源核验：为解释标注来源、适用范围和不确定性
- DS-04 综合表达：把不同角色证据组织成一条有依据、有限度的结论

## 平台能力映射说明
- CC-1.2：用可核对的语言描述现场特征
- CC-3.2：让每个结论都指向具体证据
- CQ-1：自主规划观察与记录步骤
- CQ-2：在协作中说明自己的证据并回应他人质疑
- CQ-5：遵守公共文化场所的安全、秩序、隐私与保护要求
- CQ-6：感受建筑色彩、材质与空间形成的秩序
```

### 5.2 填写说明

- 新课程定义 `DK-*` 与 `DS-*`；ID 必须与任务中的 `能力标签` 完全一致。
- `CC-*`、`CQ-*` 的正式含义以 `_platform/competency-framework.md` 为准，本课只做映射说明，不重新定义平台树。
- 新课程不新增 `DC-*`；它只用于迁移存量课程的自定义核心能力。
- 每个目标写成“内容/能力名称 + 可理解的目标描述”，避免只有口号。

```md
## Phase 2：现场双线采证
- 时长：75min
- 模式：按角色个人调查，同角色可短协作
- 地点：教师批准的开放参观区域

1. 两类角色分别完成现场任务

4. 教师组织学生返回集合空间
```

```md
| 等级 | 定义 | 使用原则 |
|---|---|---|

| B | 同组成员取得且可追溯的现场证据 | 引用时标出贡献者和证据编号 |
| C | 有主体、日期/版本的课程资料或正式来源 | 可支持背景或解释，仍需说明适用对象 |

- 现场采证未违反开放区域、秩序、文物保护和隐私规则。
```
