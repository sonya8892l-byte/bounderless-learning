# 物种档案员分级脚手架

## 任务1：建立档案骨架
| 层级 | 提示 |
|---|---|
| L0 | 自己列出最想查的档案字段。 |
| L1 | 身份、分布、栖息地、食性、种群中选四项。 |
| L2 | 每项改写成一个问题。 |
| L3 | 给每个问题匹配来源类型。 |
| L4 | 教师帮助缩小一个过大的字段。 |

## 任务2：现场建档
| 层级 | 提示 |
|---|---|
| L0 | 先拍来源，再写事实。 |
| L1 | 每条事实旁写照片或展签编号。 |
| L2 | 动态信息补时间和空间范围。 |
| L3 | 用“主张—来源—日期—局限”表。 |
| L4 | 请教师处理点位或来源冲突。 |

## 任务3：发布物种档案
| 层级 | 提示 |
|---|---|
| L0 | 检查五个字段和一个未知。 |
| L1 | 逐句圈出来源编号。 |
| L2 | 找不到来源的句子改成待核。 |
| L3 | 邀请两名角色交叉复核。 |
| L4 | 教师确认高风险动态字段。 |
