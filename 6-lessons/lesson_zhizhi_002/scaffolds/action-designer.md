# 行动方案设计员分级脚手架

## 任务1：定义方案成功
| 层级 | 提示 |
|---|---|
| L0 | 先写希望谁发生什么变化。 |
| L1 | 补期限和判断方法。 |
| L2 | 将证据需求分为四类。 |
| L3 | 标出可能改变方案的证据。 |
| L4 | 教师帮助收窄目标边界。 |

## 任务2：模拟资源配置
| 层级 | 提示 |
|---|---|
| L0 | 先确定一个优先目标。 |
| L1 | 每项资源绑定风险或缺口。 |
| L2 | 写出暂缓什么。 |
| L3 | 约束变化后找受影响的依赖。 |
| L4 | 教师澄清模拟规则。 |

## 任务3：发布守护行动书
| 层级 | 提示 |
|---|---|
| L0 | 自查七要素。 |
| L1 | 每项行动追溯风险和缺口。 |
| L2 | 补听证处置与版本变化。 |
| L3 | 补AI披露、人工核验和待核。 |
| L4 | 教师确认发布边界。 |
