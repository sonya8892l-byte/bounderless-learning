# 名录核验员分级脚手架

## 任务1：拆分保护标签
| 层级 | 提示 |
|---|---|
| L0 | 先判断每句话回答什么问题。 |
| L1 | 用法律、IUCN、趋势、成效四个盒子。 |
| L2 | 不够判断的放入待核。 |
| L3 | 写“知道A仍需另查B”。 |
| L4 | 教师用非本物种例子演示一次。 |

## 任务2：核验版本与范围
| 层级 | 提示 |
|---|---|
| L0 | 自查来源、版本、范围和日期。 |
| L1 | IUCN条目先找评估年。 |
| L2 | 趋势至少需要可比较时点或来源判断。 |
| L3 | 使用五字段核验表。 |
| L4 | 教师确认法规效力或数据口径。 |

## 任务3：出具核验说明
| 层级 | 提示 |
|---|---|
| L0 | 四类结论独立成行。 |
| L1 | 每行补来源编号。 |
| L2 | 冲突信息并列保留。 |
| L3 | 列出必须人工核验项。 |
| L4 | 教师完成签注，未核项保留待核。 |
