# 利益相关者观察员分级脚手架

## 任务1：建立相关者假设图
| 层级 | 提示 |
|---|---|
| L0 | 自己列与威胁和措施有关的人。 |
| L1 | 谁决策、执行、受影响、提供知识？ |
| L2 | 每类补一条关系。 |
| L3 | 把态度判断改成开放问题。 |
| L4 | 教师处理刻板或敏感表达。 |

## 任务2：绘制影响与公平图
| 层级 | 提示 |
|---|---|
| L0 | 区分证据、推断、待询问。 |
| L1 | 两项措施各问谁受益。 |
| L2 | 再问谁承担成本、谁缺席。 |
| L3 | 提出补救或替代。 |
| L4 | 教师处理隐私材料。 |

## 任务3：主持相关者质询
| 层级 | 提示 |
|---|---|
| L0 | 问具体行动会怎样影响谁。 |
| L1 | 覆盖影响、成本、参与三类。 |
| L2 | 每条意见记录处置状态。 |
| L3 | 补采纳理由和修改位置。 |
| L4 | 教师维持听证规则。 |
