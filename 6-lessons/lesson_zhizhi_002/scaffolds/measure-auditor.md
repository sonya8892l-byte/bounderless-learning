# 保护措施审计员分级脚手架

## 任务1：定义审计问题
| 层级 | 提示 |
|---|---|
| L0 | 先问材料说“做了”还是“改变了”。 |
| L1 | 放入投入—活动—产出—结果—目标。 |
| L2 | 为目标补一个指标。 |
| L3 | 写基线和需要的成效资料。 |
| L4 | 教师帮助解释复杂指标。 |

## 任务2：审计措施与缺口
| 层级 | 提示 |
|---|---|
| L0 | 每项措施先连到一个威胁。 |
| L1 | 再补主体、活动和成效证据。 |
| L2 | 证据不足写“效果待核”。 |
| L3 | 从覆盖、执行、资源、监测找缺口。 |
| L4 | 教师排除不安全行动。 |

## 任务3：报告审计结果
| 层级 | 提示 |
|---|---|
| L0 | 各找一项保留、改进和缺口。 |
| L1 | 每项补矩阵编号。 |
| L2 | 需要的指标单列。 |
| L3 | 逐项追溯行动书。 |
| L4 | 教师确认高风险结论边界。 |
