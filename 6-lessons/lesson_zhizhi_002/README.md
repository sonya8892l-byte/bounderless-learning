# lesson_zhizhi_002

深度探究版《万兽城议事厅Ⅱ：物种守护调查》的课程源包。

## 教研备忘（不参与运行）

### 调查边界

> 教研说明：本节记录全课调查与核验边界；具体运行时限制仍以 `course.md / 课程限制规则`、Phase Prompt 与 Step 引用为准。
- 默认从馆方确认的代表物种中选择；每组记录主点、替代点和展签照片编号。
- 法律保护身份、IUCN受威胁等级、种群趋势和措施成效分别核验，不互相替代。
- 所有动态信息记录材料发布日期、学生访问日期和人工核验人。
- AI负责检索建议、证据整理、追问和版本比较，不替学生作风险判断或资源取舍。
- 正式实施前由馆方或动物学专家复核展品点位、展签原文与动态保护信息。

## 运行结构
- 6阶段、6角色；每个角色3个角色阶段，每阶段2个Step。
- B1知识卡来自 `knowledge/*.md`，AI按角色、证据进度和揭示时机开放。
- `time-bank.md` 已启用，提供核验、现场证据和方案修订支线；余额不替代证据闸门。
- `assets/placeholders/` 只保证课程引用可解析，正式视觉素材见 `assets-checklist.md`。

## 实施前检查
1. 由馆方确认主点、替代点、拍摄规则和集合区。
2. 由专家复核物种点位、展签原文、法律身份、IUCN版本与趋势材料。
3. 教师填写动态来源的发布日期、访问日期和人工核验人。
4. 先小规模试跑证据墙、资源模拟和听证节奏。
