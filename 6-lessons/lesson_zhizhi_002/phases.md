# 阶段编排

## Phase 1：调查开题
- 时长：30min
- 模式：情境导入 + 小组开题
- 地点：教育空间
- 功能模块：A06(沉浸媒体), A01(文字), A05(讨论)
- 触发条件：教师手动启动
- 结束条件：物种、核心问题、证据计划和角色分工明确

### 流程
1. 阅读一份信息相互矛盾的“保护简报”。
2. 区分保护身份、受威胁等级、种群趋势与措施成效。
3. 选择物种并提出可调查的核心问题。
4. 制定六线取证计划和来源编号规则。

### 阶段任务1：提交调查开题卡
- id：phase-1-task-1
- 执行单位：个人
- 配置：记录小组物种、核心问题、六线取证计划和来源编号规则
- 通过条件：四项开题信息齐全，核心问题可调查，来源编号规则可执行
- 收口方式：auto_on_last_step
- 推进方式：auto_after_validation
- 位置模式：none
- 地点：教育空间
- 建议时长：8min
- 无操作提醒：8min
- 提醒冷却：8min
- 最大主动提醒：1
- 功能模块：A01(文字表单)
- 工具参数：{"text":{"fields":[{"id":"species","label":"调查物种","type":"short_text","required":true,"minLength":2,"maxLength":30},{"id":"question","label":"可调查的核心问题","type":"long_text","required":true,"minLength":20,"maxLength":180},{"id":"plan","label":"六条证据线怎样分工","type":"long_text","required":true,"minLength":60,"maxLength":500},{"id":"source-rule","label":"来源编号规则","type":"long_text","required":true,"minLength":20,"maxLength":180}]}}
- 完成方式：ai_evaluation
- 证据要求：物种、核心问题、六线分工和来源编号规则各一项
- 能力标签：CC-1.2, CQ-1, DS-01
- AI引导方向：检查问题与证据计划是否可执行，不给物种风险的标准诊断

##### 引导
先请学生指出简报中的一条具体主张，再区分它属于保护身份、受威胁等级、种群趋势还是措施成效；一次只修正开题卡中的一个首要缺口。

##### 验收标准
物种明确；核心问题可由后续多源证据推进；六条证据线均有调查方向；来源编号能区分来源、日期和版本。结论是否正确不影响开题通过。

#### Step 1：完成四项开题信息
- id：phase-1-task-1-step-1
- 小步目标：建立角色选择后可共同使用的调查起点与来源规则
- 学生行动：填写调查物种、核心问题、六线分工和来源编号规则
- 位置：none
- 完成方式：ai_evaluation
- 证据要求：四项信息齐全且能支持后续多源取证
- 功能模块：A01(文字表单)
- 工具参数：{"text":{"fields":[{"id":"species","label":"调查物种","type":"short_text","required":true,"minLength":2,"maxLength":30},{"id":"question","label":"可调查的核心问题","type":"long_text","required":true,"minLength":20,"maxLength":180},{"id":"plan","label":"六条证据线怎样分工","type":"long_text","required":true,"minLength":60,"maxLength":500},{"id":"source-rule","label":"来源编号规则","type":"long_text","required":true,"minLength":20,"maxLength":180}]}}
- 常见误区：把保护身份、受威胁等级、种群趋势和措施成效合成一个结论
- 最大尝试：3
- 失败处理：只指出物种、核心问题、六线分工或来源规则中的首要缺口
- 教师介入：小组无法确定物种、研究范围或可用来源
- 通过后：role-stage:complete

##### 验收标准
四项信息齐全；核心问题可调查；六线分工不重复；来源编号规则可以在后续证据墙中执行。

## Phase 2：展厅多源取证
- 时长：90min
- 模式：角色分线 + 两次汇合
- 地点：踏勘确认的展厅点位
- 功能模块：A07(实物识别), A01(拍照/文字), A05(证据墙)
- 触发条件：开题通过教师确认
- 结束条件：每条关键主张至少有现场来源，动态主张有第二来源或待核标记

### 流程
1. 获取标本、展签、展陈图表和馆方资料。
2. 用“来源—主张—日期—局限”格式登记证据。
3. 将一致、冲突和缺失信息分别上墙。
4. 教师完成第一次来源与点位抽检。

## Phase 3：风险诊断
- 时长：45min
- 模式：小组建模
- 地点：教育空间
- 功能模块：A03(趋势图/威胁链), A05(核验)
- 触发条件：证据墙达到最低完整度
- 结束条件：风险诊断包含趋势、直接威胁、驱动因素和不确定性

### 流程
1. 绘制带时间与来源的种群趋势。
2. 搭建“人类活动—环境变化—直接威胁—种群结果”链。
3. 对威胁重要性和证据强度分别评分。
4. 保留至少一个替代解释或未知项。

## Phase 4：保护措施审计
- 时长：45min
- 模式：审计工作坊
- 地点：教育空间
- 功能模块：A03(审计矩阵), A04(资源模拟)
- 触发条件：风险诊断通过小组复核
- 结束条件：形成措施—威胁对应表、成效证据和保护缺口清单

### 流程
1. 核对每项措施试图改变哪一段威胁链。
2. 区分“已经开展”与“已有成效证据”。
3. 用覆盖度、可执行性、公平性和可监测性审计。
4. 识别保护缺口并模拟有限资源配置。

## Phase 5：方案听证
- 时长：40min
- 模式：利益相关者听证 + 版本修订
- 地点：教育空间
- 功能模块：A05(听证), A04(方案答辩)
- 触发条件：审计和缺口清单完成
- 结束条件：方案回应至少三类利益相关者，并完成一次有记录的修订

### 流程
1. 公布方案目标、行动、责任主体、资源与指标。
2. 利益相关者代表从影响、成本和公平性提出质询。
3. 调查组用证据回应，不能回答的列入待核。
4. 记录采纳、部分采纳或暂不采纳及理由。

## Phase 6：行动书发布
- 时长：20min
- 模式：小组发布 + 同伴评议
- 地点：教育空间
- 功能模块：A01(文档), A05(互评)
- 触发条件：听证修订完成
- 结束条件：行动书通过来源、逻辑、执行和边界四项检查

### 流程
1. 发布物种档案、风险诊断、措施审计和保护缺口。
2. 提交含目标、行动、主体、资源、指标和复盘日期的行动书。
3. 披露AI使用位置、人工核验人和未解决问题。
4. 每组接受一次可追溯的证据质询。
