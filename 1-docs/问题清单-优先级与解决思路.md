## 0. 已定案的架构前提（不再讨论，变更需重新评审）

- **目标管线**：平台包＋课程包 md → 统一编译器（校验→合并→装配任务图）→ **Course IR**（唯一中间表示，内容 hash 版本化）→ 三投影（公开/智能体/教师）→ 对话线＋闯关线（同一进度源）。
- **D1** 任务单元内联在 `roles/<role>.md`：Step＋引导＋脚手架＋验收标准就地同居；guidance/、scaffolds/ 目录取消。
- **D2** `前置`（入边）为进度语义权威；`通过后` 保留为线性语法糖，编译期转换。
- **D3** 就地：引导/脚手架/Step 验收标准；集中：知识/限制/课程级量规/时间银行。
- **D4** 覆盖白名单——不可覆盖：三底线＋絮絮名字底色；可覆盖：语气侧面/话术模板/学段规范/工具与时长缺省。
- **D5** 迁移：脚本一次迁完 5 门课＋人工抽查，短双格式兼容期。
- **D6** 运行层"语义理解优先"（乙案）：**一切语言输入必经轻量 LLM 语义理解，规则只处理非语言输入与状态机；进度判定保持确定性**。分界线是"语言/非语言"，不是"高置信/低置信"。
- **评价边界**（既定约束）：只做标签空间预留（CC/DK/DS/CQ 四棵树＋任务级标签字段，不进公开包、不进 Prompt、无 UI、无计算），不做画像/评价功能。

## 3. 轨道二 · 运行时智能体

### R1：语义理解优先（乙案落地）★ 整个计划的第一优先

**为什么最先**：治的是线上正在发生的体验硬伤（"你好"/"我不知道从哪里开始"被正则曲解 → 套话顶回 → 死循环）；且不依赖 IR/两包重构，可与 M0 同周开工。

- **内容**：
  1. `routeInput` 输入分流：语言输入（自由文字）vs 非语言输入（工具结果/位置/心跳/带 questionId 按钮）；
  2. `understandTurn`：由现有"回合理解器"升级——从"待答问题时才调"提为**语言输入必经第一站**（jsonMode 结构化输出：意图/情绪/是否在答待答问题/想要什么/置信度）；同时**删除 classifyTurn 对自由文本的全部正则猜测**；
  3. `tutorPolicy`：确定性教学决策——结合任务小步、待答问题、脚手架等级、**提醒历史**（同样的求助第二次来必须换策略，防复读防循环）；
  4. 回应：闲聊寒暄由轻量模型直接自然生成（允许与理解合并为一跳），先接住学生这句话；课程相关走 检索＋主模型（现有链路）；全部输出过 findSpoiler；
  5. **降级链**：理解调用 zod 校验 → 超时/失败重试一次 → 落保守缺省（接住＋温和追问一句），**绝不回落会循环的正则分支**；
  6. 配置：同一 OPENAI 网关新增轻量模型配置项（如 `OPENAI_UNDERSTAND_MODEL`），沿用现有超时不变式体系。
- **测试改造**：`agent.test.js` "问候不调模型"→"问候只调轻量模型一次、不检索课程知识、不调主模型"；"整轮只调一次模型"→"主模型至多一次"；**新增防循环回归集**：≥10 条真实话术（你好/不知道从哪开始/这是什么/我累了/你有毒吧/直接告诉我答案 等），断言回应引用学生语义且连续两轮不重复同一话术。
- **吸收问题**：A3-意图理解部分（方案由"规则先行小模型仲裁"改为"语义理解必经"，D6 定案）。
- **DoD**：防循环回归集全绿；语言回合 P50 延迟增量 ≤0.6s；理解调用失败注入测试下降级链行为正确；正则意图分支代码删除。
- **成本**：4–6 天（含测试改造）。

### R2：五层拆分（机械重构，行为不变）

- **内容**：service.js（1360 行）按 回合理解 / 教学决策 / 回应生成 / 状态执行 / 事件持久化 五层拆文件；R1 的 routeInput/understandTurn/tutorPolicy/composeReply 归位到前三层；102 项存量测试护航。
